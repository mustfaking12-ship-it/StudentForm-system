# قاعدة المزامنة التلقائية مع GitHub (Git Auto-Sync Rule)

- عند إنجاز أي تعديل، إضافة ميزة، أو إصلاح لأي كود أو ملفات في هذا المشروع بناءً على طلب المستخدم:
  - قم بتنفيذ `git add .`
  - قم بتنفيذ `git commit -m "وصف التغيير"`
  - قم برفع التغييرات مباشرة إلى المستودع: `git push origin main`
- إعلام المستخدم بنجاح عملية الرفع ورابط الـ Commit.
