# نظام استمارة معلومات الطالبات والملاكات التدريسية والإدارية
## مدرسة المتفوقات الأولى للبنات - وزارة التربية العراقية (نظام EMIS المعتمد)

نظام إلكتروني متكامل واحترافي لجمع وإدارة معلومات الطالبات والملاكات التعليمية والإدارية، تم تصميمه ومطابقته بدقة مع استمارة وزارة التربية العراقية الرسمية لنظام EMIS.

---

### ✨ المميزات الرئيسية للنظام

1. **الصفحة الرئيسية الترحيبية**:
   - واجهة عصرية وسهلة تحتوي على الأيقونتين الأساسيتين:
     - 🎓 **[ استمارة معلومات طالبة ]**
     - 👩‍🏫 **[ استمارة مدرس / موظف ]**
   - صندوق استعلام سريع عن الاستمارات السابقة بواسطة الرمز التعريفي (`STU-000001` أو `TEA-000001`).
   - رابط بوابة الإدارة للدخول الآمن.

2. **حقل الاسم الرباعي الموحد (شرط إلزامي)**:
   - تم إلغاء التجزئة تماماً (لا يوجد حقل أول، ثانٍ، ثالث...).
   - حقل موحد: **"الاسم الرباعي *"** للطالبة، والمدرس، وولي الأمر.
   - فحص وتدقيق ذكي في الوقت الفعلي يمنع الأسماء الأقل من 4 كلمات مع إظهار عدد الكلمات (مثال: `مصطفى حسن جاسم محمد`).

3. **معمارية خطوات متعددة (Multi-Step Wizard)**:
   - الخطوة 1: المعلومات الشخصية والنسب (مع رفع الصورة الشخصية).
   - الخطوة 2: وثيقة التعريف والبيانات الرسمية (البطاقة الموحدة / هوية الأحوال / السجل / الصحيفة).
   - الخطوة 3: السكن والاتصال وعناوين الطوارئ (المحلة، الزقاق، الدار، أقرب نقطة دالة).
   - الخطوة 4: الاحتياجات الخاصة (تفعيل ديناميكي سلس عند اختيار "يوجد").
   - الخطوة 5: المعلومات الدراسية (للطالبة) / المعلومات الوظيفية (للموظف والمعلم).
   - الخطوة 6: معلومات ولي الأمر (للطالبة) / المؤهلات العلمية والشهادات (للمدرس).
   - الخطوة 7: المراجعة الشاملة والتأكيد قبل الحفظ والإرسال.

4. **الحفظ التلقائي للمسودة (Auto-Save / Draft)**:
   - حفظ تلقائي غير متزامن في التخزين المحلي للمتصفح (`LocalStorage`) لحماية البيانات من الضياع عند انقطاع الاتصال أو تحديث الصفحة، مع إمكانية استرجاع المسودة أو مسحها.

5. **نظام منع التكرار الذكي (Duplicate Prevention)**:
   - فحص فوري ومقارنة الاسم الرباعي وتاريخ الميلاد ورقم الهاتف والبطاقة الوطنية.
   - تنبيه فوري بمربع حوار عند الاشتباه بوجود سجل سابق مع إمكانية معاينة السجل.

6. **لوحة تحكم إدارة المدرسة (Admin Dashboard)**:
   - خاصة بمدير النظام والموظفين المصرح لهم.
   - بطاقات إحصائية للأرقام الحية: إجمالي السجلات، الطالبات، المدرسين، الموظفين، الذكور، الإناث، والحالات النشطة.
   - رسوم بيانية تفاعلية (Chart.js) لتوزيع المراحل الدراسية ونسب الجنس.

7. **إدارة السجلات والبحث الذكي**:
   - جدول تفاعلي مع فرز وفلاتر حسب الصف، المرحلة، الحالة، ونوع السجل.
   - محرك بحث ذكي يتجاوز اختلاف الهمزات (أ، إ، آ) والألف المقصورة والتاء المربوطة.
   - إجراءات متكاملة: (معاينة شاملة 👁️، تعديل فوري ✏️، طباعة رسمية A4 🖨️، حذف آمن 🗑️).

8. **استمارة الطباعة الرسمية A4**:
   - تصميم مطابق ومحاكي للاستمارة الورقية الرسمية الصادرة من وزارة التربية العراقية (نظام EMIS).
   - إطار رسمي مزدوج، ختم الإدارة، وتواقيع المنظم والموظف وولي الأمر.
   - جاهزة للطباعة المباشرة على ورق قياس A4 بضغطة زر.

9. **تصدير واستيراد Excel / CSV**:
   - تصدير فوري لملفات Excel و CSV مع دعم كامل لترميز اللغة العربية (UTF-8 مع BOM) لمنع ظهور أي رموز مشوهة في برنامج Microsoft Excel.
   - استيراد ملفات مع شاشة معاينة (Preview) واكتشاف السجلات المكررة قبل الاعتماد النهائي.

### 🚀 تشغيل النظام محلياً

#### 1. تشغيل الخادم الخلفي (Backend):
```bash
cd backend
npm install
node src/server.js
```
يعمل الخادم على: `http://localhost:5000`

#### 2. تشغيل واجهة المستخدم (Frontend):
```bash
cd frontend
npm install
npm run dev
```
تعمل الواجهة على: `http://localhost:3000`
